# Registros de Decisão de Arquitetura de Hardware (Hardware ADR)

Este diretório contém as decisões formais de engenharia de circuito, seleção de componentes e diretrizes de layout da placa `placa_fechamento`.

## Índice de Decisões
- *Os ADRs serão adicionados e numerados sequencialmente à medida que os blocos de circuito forem definidos.*
