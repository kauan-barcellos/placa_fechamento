# Pacotes de Fabricação e Montagem (JLCPCB)

Este diretório armazena os arquivos de saída gerados após a aprovação do DRC da PCB:

## Estrutura de Pastas

- **`gerbers/`**: Arquivos Gerber RS-274X / X2 e brocas Excellon para fabricação de PCB.
- **`assembly/`**: Lista de Materiais (**BOM**) padronizada com códigos LCSC Part # e arquivo de posicionamento de componentes (**CPL / Pick & Place**).
- **`pdf/`**: Documentação visual em PDF contendo o esquemático elétrico completo, visualizações de montagem e diagramas de pinagem.
