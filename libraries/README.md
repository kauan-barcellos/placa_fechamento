# Bibliotecas de Componentes Locais

Este diretório armazena símbolos e footprints personalizados do projeto caso algum componente específico não esteja disponível nas bibliotecas oficiais padrão do KiCad 10.0.

## Estrutura de Arquivos

- **`symbols/`**: Arquivos `.kicad_sym` contendo símbolos esquemáticos customizados.
- **`footprints.pretty/`**: Diretório `.pretty` contendo pegadas físicas `.kicad_mod` personalizadas.
- **`3dmodels/`**: Modelos 3D STEP / WRL para visualização tridimensional e checagem de colisões mecânicas.
