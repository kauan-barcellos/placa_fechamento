# Documentação Técnica - Projeto Placa de Fechamento

Este diretório contém a documentação complementar de engenharia, especificações detalhadas dos circuitos, diagramas conceituais em blocos e relatórios de cálculos.

## Estrutura dos Documentos

- **`especificacoes_tecnicas.md`**: Requisitos funcionais, elétricos e ambientais do projeto (alimentação, interfaces, sensores, atuadores).
- **`pinout_mcu.md`**: Mapeamento de pinos, periféricos e funções de multiplexação (GPIOs, USART, SPI, I2C, Timers/PWM).
- **`calculos_potencia.md`**: Dimensionamento de condutores, dissipação térmica, reguladores de tensão e quedas de tensão.
